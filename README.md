# BookMyStayApp

A Core Java based Hotel Booking Management System developed to demonstrate the real-world application of programming fundamentals and data structures through incremental use cases.

---

## Running Procedure

1. Open terminal in the project folder
2. Compile the program:

   javac UseCase1HotelBookingApp.java

3. Run the program:

   java UseCase1HotelBookingApp

4. The application welcome message will be displayed on the console.

---

## Flow of Project

The project is developed step-by-step using multiple use cases.

**Flow:**

User runs application  
↓  
JVM invokes main() method  
↓  
Program executes business logic  
↓  
Output displayed to user  
↓  
Application terminates safely

Each new use case adds features like booking logic, room management, and customer handling.
